<details>
<summary>项目文字介绍与开发状态</summary>

[Glassbox](https://github.com/lora-sys/Glassbox-Agent-Harness) 是开发中的 Personal Agent 系统。当前计划包含 QQ 接入、身份与权限、对话存储，以及将任务交给 coding worker 执行。Pi、Lora PI Kit 与 Glassbox 的分工见[当前开发计划](https://github.com/lora-sys/Glassbox-Agent-Harness/blob/main/.plans/03-personal-agent-foundation.md)。

[Zhihu Threads](https://github.com/lora-sys/zhihu-threads) 使用用户选中的知乎摘录生成学习线，支持追问、自测与导出。回答范围限于所选摘录。

[AgentArena](https://github.com/lora-sys/AgentArena) 让三支 Agent 团队处理同一任务，保留提案、修订、证据和回放。真实模型运行与固定演示回放是两种不同模式。

[Lora Skills](https://github.com/lora-sys/skills) 是可单独安装的 Agent Skills 集合。自有与改编技能的来源、许可分别说明。

[nano-vLLM 交互教程](https://github.com/lora-sys/nano-vllm-interactive-guide) 基于上游 nano-vLLM 源码，用中文章节和浏览器实验讲解推理引擎。

[Free Vision Skill](https://github.com/lora-sys/free-vision-skill) 按任务提取图片中的相关信息，将文本证据交给 Agent 继续处理。

</details>
